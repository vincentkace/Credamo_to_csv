# Credamo Downloader 改造笔记

## 一、原项目功能分析

### 1.1 Selenium版本功能模块

| 模块名 | 功能 | 对应函数 |
|--------|------|----------|
| 登录模块 | 打开网站，检测登录状态 | `open_credamo` |
| 获取项目ID | 从URL解析surveyId，检查是否在数据清理页面 | `get_surveyId` |
| 页面设置 | 设置每页显示条数、跳转页码 | `set_page_size`, `go_to_page` |
| 数据获取 | 调用API获取问卷数据 | `get_page_df` |
| 数据下载 | 批量下载所有页数据到Excel | `download_data` |
| 批量拒绝 | 读取Excel中userId，批量拒绝被试 | `batchReject`, `get_userId_loc` |
| 批量接受 | 接受剩余未被拒绝的被试 | `batchAccept`, `get_accept_userId_loc` |
| GUI界面 | Tkinter界面 | 底部GUI代码 |

### 1.2 API调用分析

- 数据API: `https://www.credamo.com/v1/cleanVar/qstOverviewBySurId/{surveyId}?currPageSize={page_size}&currPageIndex={page_num}`
- 需要从浏览器获取cookie
- Referer需要设置为项目URL

### 1.3 页面交互

- 点击"数据清理"按钮进入数据清理页面
- 设置每页显示条数（5/10/30/50/100）
- 分页跳转
- 勾选被试（checkbox）
- 点击"批量拒绝"/"批量接受"下拉菜单
- 选择拒绝原因

## 二、反爬绕过代码（credamo_bypass.py）

### 2.1 浏览器启动参数
```python
browser = p.chromium.launch(
    headless=False,
    channel="chrome",
    user_data_dir="./browser_data",  # 保存登录状态
    args=[
        "--start-maximized",
        "--disable-blink-features=AutomationControlled",
        "--disable-infobars",
        "--no-default-browser-check",
        "--disable-dev-shm-usage",
    ]
)
```

## 三、改造规划

### 3.1 模块划分

| 文件 | 内容 |
|------|------|
| `browser.py` | 浏览器启动和反爬注入（复用bypass.py） |
| `api.py` | 数据API调用（requests） |
| `page_ops.py` | 页面操作（点击、勾选、跳转） |
| `gui.py` | Tkinter界面 |
| `main.py` | 主程序入口 |

### 3.2 Playwright vs Selenium对照

| Selenium | Playwright |
|----------|-------------|
| `browser.find_element_by_xpath` | `page.locator().click()` |
| `browser.get_cookies()` | `context.cookies()` |
| `browser.current_url` | `page.url` |
| `WebDriverWait` | `page.wait_for_selector()` |
| `browser.find_elements` | `page.locator().all()` |

### 3.3 实施顺序

1. **browser.py** - 创建浏览器实例（复用bypass.py代码）
2. **api.py** - 封装API调用，保持不变
3. **page_ops.py** - 页面交互操作改造
4. **gui.py** + **main.py** - GUI和主逻辑整合

---

## 四、注意事项

1. `channel="chrome"` 需要本机安装Chrome浏览器
2. `user_data_dir` 指定固定目录保存登录状态
3. Playwright的等待机制更智能，尽量用`wait_for_selector`代替`sleep`
4. XPath语法基本兼容，但部分定位方式需要调整
